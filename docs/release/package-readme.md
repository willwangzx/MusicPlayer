# MusicPlayer 便携版 — 使用说明

这是朋友之间私人分享的 Windows x64 便携版本,解压即用,免安装。

## 系统要求

- Windows 10 / 11(64 位)
- WebView2 运行时:Windows 11 和大多数已更新的 Windows 10 已内置。
  若启动时提示缺少 WebView2,请到微软官网安装
  "WebView2 Evergreen Runtime" 后重试。
- 无需安装 Python、Node.js 或其他依赖。

## 第一次使用

1. 把整个文件夹解压到一个固定位置(例如 `D:\Apps\MusicPlayer`,
   不要放在临时目录里)。程序的所有运行文件都在这个文件夹内。
2. 音乐库路径固定为 `D:\Music`(本版本不支持更改):
   把音乐文件放进 `D:\Music`,子文件夹随意组织;
   `D:\Music\.downloads` 是下载暂存目录,会被扫描自动排除。
3. 双击 `music-player.exe` 打开。
   Windows 首次运行可能提示"Windows 已保护你的电脑"(未签名程序),
   点击"更多信息"→"仍要运行"即可。
4. 点击 "Scan library" 建立曲库索引。扫描是只读的,
   不会移动、重命名、覆盖或修改你的任何音乐文件。
   扫描完成后即可在 Tracks / Albums 中浏览和播放。

## 日常使用

- 关闭窗口(包括 Alt+F4)= 最小化到系统托盘,播放不中断。
  单击托盘图标恢复窗口;托盘右键菜单"彻底退出"才会真正退出。
- 队列、音量、上次播放位置会自动保存,下次打开后手动按播放恢复。
- 曲库有变化后重新点 "Scan library" 刷新;扫描期间旧索引仍可正常使用。
- 删除文件:界面里的 "Delete file" 会让你先确认具体文件,
  确认后移入 Windows 回收站(可从回收站还原)。
  除此之外程序绝不会动你的音乐文件。

## 可选:Apple Music 下载

本地播放完全独立,不配置下载器不影响任何本地功能。
若要启用下载,请解压配套的组件包(另一个压缩包),
并按其中的 README.txt 完成一次性配置。

## 数据与卸载

- 应用状态(曲库索引、队列、设置)保存在:
  `%LOCALAPPDATA%\MusicPlayer\state`
- 卸载 = 删除本文件夹;如需彻底清理,再删除上面的 state 文件夹
  (删除后曲库索引和队列会丢失,重新扫描即可恢复曲库)。
